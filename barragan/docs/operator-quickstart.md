Copyright (c) 2026, Oracle and/or its affiliates.

Start with [installation and configuration](../README.md). Configure your own
provider connections, team identities, deployment target registry and private
runtime directory. The source export contains no preconfigured engagement.

Create an engagement in the console, select an approved deployment target and
review the generated plan before applying it. Configure the intended connection
path, capabilities and routes for that engagement. Existing deployments retain
their source and state identities; this export does not migrate them.

The keyed workflow remains opt-in and restricted to its configured pilot scope.
The control-plane host must use the managed connection path for edge management;
public edge connectivity checks use an explicitly configured external Inspector.

Keep service configuration, credentials, account data and operational evidence
outside the source tree. Optional app adapters and their administrator-prepared
artifacts are described by the separate AI integration publication.
